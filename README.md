# Brief Builder

Creative brief training guide for H-E-B Marketing: the rules, tools and examples from the two-day LPA creative brief and creative feedback training, with studio timelines.

Site: https://mktg-ops.github.io/brief-builder/

## How it works

- `index.html` is the whole site: one self-contained file (HTML, CSS and the tools).
- GitHub is the master copy. Edits are made here and go live on push.
- Do not push to this repository from Figma Make. Make's push overwrites the repository.

## What's inside

1. How a brief works
2. Field guide
3. Insight builder
4. Objectives
5. Timeline and studio (calculator skips weekends and major holidays)
6. Ready to send
7. Giving feedback
8. Examples
9. Brief Coach and AI (Copilot, Claude and Gemini)
10. Glossary

Items still being confirmed are marked Proposed.
